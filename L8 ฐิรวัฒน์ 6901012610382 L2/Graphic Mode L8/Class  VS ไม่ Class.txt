แบบไม่ใช้ Class (List ซ้อน List)
ข้อมูลถูกเก็บเป็น Index เช่น b[0], b[1], b[2] ทำให้ต้องจำว่า index ไหนคือค่าอะไร
ฟังก์ชันและตรรกะการเคลื่อนที่กระจายอยู่นอกข้อมูล ต้องสั่งเปลี่ยนค่าผ่าน Array ตรงๆ ใน

แบบใช้ Class (OOP)
ข้อมูลถูกเก็บในชื่อ Attribute ชัดเจน เช่น self.x, self.speed ทำให้อ่านและเข้าใจง่าย
รวมทั้งข้อมูล (Attributes) และการทำงาน (show(), update()) ไว้ในวัตถุเดียวกันตามหลัก Encapsulation
